# Amazon Web Project

Este proyecto es una replica de estilo Amazon de una tienda en línea, desarrollada con HTML, CSS y JavaScript. La aplicación simula la experiencia de compra de un e-commerce moderno, permitiendo explorar productos, agregarlos al carrito, realizar la compra y consultar el estado de los pedidos.

## Descripción

La aplicación está diseñada para mostrar una experiencia de compra dinámica y visualmente similar a la de una tienda online popular. Incluye una página principal con catálogo de productos, un carrito de compras, un proceso de checkout y una sección para seguimiento de pedidos.

## Características

- Catálogo de productos con imágenes, precios y valoraciones
- Búsqueda de productos
- Agregar artículos al carrito
- Ajustar cantidades de productos
- Cálculo automático del total de compra
- Página de checkout
- Historial y detalles de pedidos
- Seguimiento de entregas
- Diseño responsivo para dispositivos móviles y escritorio

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- JSON para almacenamiento de datos de productos
- Diseño estático con interfaz moderna y responsiva

## Objetivo del proyecto

Este proyecto tiene como finalidad practicar y reforzar conceptos de desarrollo web frontend, incluyendo:

- manipulación del DOM
- renderizado dinámico de datos
- lógica de carrito de compras
- gestión de estados en la interfaz
- diseño de páginas e-commerce
- trabajo con archivos estáticos y datos locales

## Cómo ejecutar el proyecto

1. Clona este repositorio.
2. Abre la carpeta del proyecto en tu editor de código.
3. Ejecuta la aplicación con un servidor local (por ejemplo, Live Server en VS Code).
4. Abre la página principal del proyecto en el navegador.

## Estructura del proyecto

- Página principal con productos
- Carrito de compras
- Checkout
- Pedidos
- Tracking o seguimiento de entregas
- Archivos de estilo y scripts

## Estado del proyecto

Proyecto en desarrollo como práctica de frontend para simular una tienda online con funcionalidades básicas de e-commerce.


Proyecto desarrollado como ejercicio de aprendizaje en JavaScript y diseño web.
